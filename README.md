# dsh-session-marks

像批改论文一样标注对话：**划选回答里的任意文字 → 挂上你的问题 → 所有标注自动汇成一条针对性提问**。

长对话里最难的不是看到答案，而是问到点上。你心里清楚「就是这三处」，但模型只看到一条连续的历史。这个插件让位置变成可以点选的东西。

## 用法

1. **划选**回答里的任意片段（可以跨行、跨内联代码或加粗；单行内即可）
2. 选区旁立刻浮出输入框，**光标已在里面**
3. 打你的问题，按 `Enter`
4. 重复以上步骤，标注任意多处
5. 所有标注会**自动同步进输入框**，格式如下：

```
下面是我在这条对话里标注的内容，请针对每一处标注后面的问题逐条回答。

[1] 第 8 轮
> 随内容自动长高
我的问题：这是什么意思

[2] 第 8 轮
> F12
我的问题：这是 DSH 自带功能吗

请按上面的编号逐条回答。
```

6. 直接按 `Enter` 发送，无需任何额外点击
7. **发送后标注自动清空**

快捷键：`Enter` 保存 · `Esc` 取消 · 点空白处放弃。

## 设计取舍

**标注不进会话日志。** 它们存在浏览器 localStorage，按 session 分桶。因此：

- 不干扰 fork、回放、压缩与 KV cache
- 标注本身**不消耗任何 token**
- 只有你真正发出去的那段文本进入上下文

代价是标注不跨设备、不同步，也不出现在会话日志里。

**高亮不改宿主 DOM。** 用 CSS Custom Highlight API（`::highlight()`）为 `Range` 上色，不包裹元素、不注入 span，因此与虚拟滚动和重渲染共存。

**锚点存文本引用而非 DOM Range。** 记录「行标识 + 字符偏移 + 原文 + 左右各 48 字上下文」。重新定位时先用偏移精确匹配，失败则用上下文夹住搜索，再退化为原文单搜索。这样行被虚拟化回收、重新渲染后标注依然能贴回原文。

## 与「划选提问」类插件的区别

如果你在找划选提问，市场里还有 `dsh-sidebar-qa` 这类方案。它们的思路是：划选一段 → 开一个**独立的后续会话**去问，不打断当前对话。

本插件解决的是另一个问题——**你一次想问好几处，而且想留在当前会话里问**：

| | 本插件 | 开独立会话类 |
|---|---|---|
| 一次标注多处 | ✅ 汇总成一条编号提问 | 通常一次一处 |
| 提问落在哪 | 原会话（保留上下文） | 新会话（上下文需重建） |
| 交互步数 | 划选 → 打字 → Enter | 划选 → 切面板 → 提问 |
| 标注生命周期 | 发送后自动清空 | 由新会话承载 |

两者可以并存：需要深挖某一处时开独立会话，需要在原对话里追问多处时用本插件。

## 安装

本插件尚未发布到 npm，从源码仓库安装即可。三种方式任选：

**方式 1：插件市场（推荐）**

已配置插件索引源的用户，在 **发现** 标签页搜索 `session marks` 或 `标注`，点安装即可。

**方式 2：插件管理器填 git 地址**

在 DSH 的 **设置 → 插件** 中，安装目标填：

```
git+https://github.com/jshonwang/dsh-session-marks.git
```

**方式 3：克隆后指向目录**

```bash
git clone https://github.com/jshonwang/dsh-session-marks.git
```

然后在插件管理器里指向克隆出来的目录。

> `client.js` 是已构建产物，无需构建步骤。`verify-render.mjs` 是开发期测试脚本，不影响安装。

## 兼容性

- 需要 DSH 的 Web GUI（本插件是纯 Client 插件，无 Host 逻辑）
- 依赖 `@deepseek-ai/dsh-client-ui-conversation` 声明的槽位
- 使用 CSS Custom Highlight API（Chromium 105+；Electron 桌面端均满足）

## 开发

```bash
# 渲染冒烟测试：加载 client.js、捕获槽位注册、用真实 React 服务端渲染
node verify-render.mjs <react安装目录> ./client.js
```

该测试覆盖：无效元素类型（`h(Component())` 这类只有在渲染时才报错的 bug）、气泡结构、键盘契约、草稿同步与发送后清理的**代码结构**（而非注释文本）。

## 已知限制

- 标注存在浏览器本地，换设备或清缓存即丢失
- 一次只能标注同一行内的内容（跨行选区会提示）
- 若宿主改为多层嵌套的 `transform`/`contain` 容器，气泡定位仍会自动校正，但极端情况下可能偏移
